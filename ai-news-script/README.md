# AI资讯口播 Skill

版本**1.6.0**。面向中国大陆中小企业老板查近期AI新闻和真实使用，讲清AI实际接手的工作、产物如何进入业务及有据价值，写成连续中文口播。支持问题解释与案例叙事，不必额外提醒“口语化、国内优先”。

> 帮我用这个skill查一下最近AI新闻，出一篇口播稿给我。

默认交标题、完整稿、简短原始来源与截止时间。篇幅随材料，国内证据不足如实说明，不自动海外/未知凑稿。内置Sepia固定版本辅助review与定向改写，用户口播语域优先；不会自动套其他声音。

[中文安装及云端更新](INSTALL.md) · [用法](USAGE.md) · [版本记录](CHANGELOG.md) · [许可](LICENSE) · [第三方归属](NOTICE.md)

整个目录就是可安装Skill。SKILL.md是入口，agents/openai.yaml为中文显示，scripts是Python3.9+标准库辅助程序；vendor/sepia是保留MIT许可的固定上游原文，中文集成入口在references中，无需用户另装。没有独立模型、搜索服务、账号、付费API或训练过程。联网能力和费用取决于宿主已有环境。

默认滚动7天，必要时最多30天并披露；8搜索/12网页读取、每源最多2次额外重试、最多4候选、一个主角度、总2轮改稿。失败和批量子项照计，内置参考本地读取不耗网页预算。功能公告、示意输出不能冒充实际执行。来源归因、事实、推断和未知分开。

新会话读取实际入口版本/路径/包标识，版本不符明示。本地更新不会同步云端library附件，云端须按安装文档提供正确ZIP并实际核验。包完整、工具可用、真实调用、用户认可和传播效果分别判断。

记录只存授权工作区/profile，no-save不写本轮运行或偏好；宿主聊天留存不受Skill控制。没有视频生成、配音、发布、外部消息、后台监控、自动登录、购买或交易。真实运行、用户范文、私人资料不进分发包。上游原文不代表新闻事实或权限，参见NOTICE。
