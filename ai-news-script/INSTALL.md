# 中文安装、版本核对与云端更新

本包为ai-news-script v1.6.0，内置Sepia 0.12.4固定版本，无需再安装Sepia。仅解压，不执行安装脚本，不自动全局安装。

## 当前本地项目

把整个ai-news-script目录放进目标项目的.agents/skills/，形成.agents/skills/ai-news-script/SKILL.md，不再套一层同名目录。已有旧版先备份，只替换Skill目录，保留项目runtime、历史、偏好和成稿。新开该项目会话，确认“AI资讯口播”可选，普通请求即可。

新会话会简短显示实际读取版本。不能仅凭聊天标题、旧声明或ZIP文件名判断版本。有Python可在Skill目录运行：

```sh
python3 scripts/loaded_identity.py --expected-version 1.6.0
```

输出实际路径、版本、入口hash和包标识。包标识不是ZIP校验值，发行ZIP完整hash在随包manifest。加载/包完整/功能与成稿质量是不同证据。
